LIVAX STUDIOS — REAL ESTATE WEBSITE

Open index.html in a browser. Click Portfolio in the top navigation to visit portfolio.html. Keep both HTML files and logo.webp together in the same folder.

This build is focused on real estate photography, cinematic property videos, and builder/interior design portfolio work.

PORTFOLIO: Example photos are from Unsplash and are NOT Livax Studios projects. Before publishing, replace image URLs in index.html and portfolio.html with your own properly licensed photos. For portfolio.html each sample tile has an image src (thumbnail) and a data-image URL (full-size lightbox image). Replace both with your own files. The Video category currently contains example stills; add links to your own films or a video player.

CONTACT: livaxstudios@gmail.com. The form uses mailto and requires the visitor to have an email app configured; it does not submit to a server.

HOSTING: Upload all files in this folder together to your web host, with index.html at the website root. External Google Fonts and sample Unsplash images require internet connectivity.
